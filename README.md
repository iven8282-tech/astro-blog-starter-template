# KidsDodoDoing — Soft Play, Built to Ship

Official B2B brand showroom and product catalog for **Wuhan Kunxiang Textile Technology Co., Ltd. (KidsDodoDoing®)**.

## 🚀 Overview

- **Brand**: KidsDodoDoing® (Wuhan Kunxiang Textile Technology Co., Ltd.)
- **Category**: Mother, Kids & Toys / Modular Foam Sofas & Soft Play
- **Domain**: [kidsdodoing.com](http://www.kidsdodoing.com)
- **Tech Stack**: React 18, Vite 5, Lucide Icons, GitHub Pages Actions

## 📦 Product Groups

1. **Kids Modular Sofa** — Modular, rearrangeable seating for playrooms and family spaces.
2. **Foam Climber Block** — Modular foam forms for active, open-ended play.
3. **Ball Pit** — Soft-play staple for indoor play centers and collections.
4. **Baby Sofa** — Compact soft seating with a nursery-friendly silhouette.
5. **Sofa Bed** — Flexible rest-and-play format.
6. **Kids Lazy Sofa** — Lightweight, relaxed children's seating.
7. **Related Toys** — Soft accessories and play pieces.
8. **Cushion & Pillow Foam** — Foam-based comfort products.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```

## 🌐 Deployment

This project includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the site to GitHub Pages on every push to `main`.
